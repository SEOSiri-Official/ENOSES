## 🌐 Universal Device Integration
ENOSES is a multimodal intelligence framework designed to be integratable on **any robotic device or electronic hardware**. 
### 🚀 Setup Instructions (Universal)
1. **Prepare Environment:**
   `bash
   git clone https://github.com/SEOSiri-Official/ENOSES_Project.git
   cd ENOSES_Project
   pip install -r requirements.txt
   `
2. **Device Calibration:**
   The system automatically detects your input hardware. To adjust sensitivity for your specific device, modify the GAIN_CALIBRATION variable in src/enoses_core.py.
3. **Run Sensing Node:**
   `bash
   python src/enoses_core.py
   `
